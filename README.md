# Sorry for My GF 💗

A cute, mobile-friendly apology website made with plain HTML, CSS, and JavaScript.

## Publish it with GitHub Pages

1. Sign in to GitHub and create a **new public repository** (for example, `sorry-for-my-gf`).
2. Upload `index.html` and this `README.md` to the repository's root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and the `/(root)` folder, then click **Save**.
6. Wait a minute or two. The Pages section will show your published website URL, usually:
   `https://YOUR-USERNAME.github.io/sorry-for-my-gf/`

Replace `YOUR-USERNAME` with your GitHub username. If you named the repository differently, use that repository name in the URL.

## Customize it

Open `index.html` and edit the apology text in the `<p class="message" id="message">...</p>` element. You can also change the page title and the text in the success message.

Everything is contained in `index.html`; there are no external libraries or image files required.
